3.
网络连接
3.1
宿主机网卡映射
（以VMware为例）
在
Windows 任务管理器
 →
性能
 页面，查看连接航插线的物理网卡名称（例如：
Realtek PCIe GbE Family Controller
）。
﻿
﻿
打开 VMware 虚拟网络编辑器，点击右下角 “
更改设置 (Change Settings
)”。找到类型为
桥接（Bridged）
 的网络适配器，在 “
桥接至（Bridge to）
” 下拉菜单中，手动选择上述记录的物理网卡。
﻿
﻿
3.2
虚拟机网络模式切换
找到虚拟机设置，点击
网络适配器
﻿
﻿
将连接方式由 NAT 改为
桥接模式 (Bridged)
，同时勾选
复制物理网络连接状态 (Replicate physical network connection state)
﻿
﻿
点击“确定”，并确保物理网线已正确连接至机器人的交换机端口
3.3
配置静态IP
在 Ubuntu 系统中，进入有线网络设置，将连接方式设为
Manual（手动）
，并配置如下参数：
●
Address (IP 地址)
:
10.21.31.100
﻿
●
Netmask (子网掩码)
:
255.255.255.0
﻿
●
Gateway (网关)
:
10.21.31.1
﻿
﻿

4.4
配置参数文件
config.yaml
附件大小：4.8KB
为实现点云的正常接收与话题融合，修改配置文件
～/rslidar_ws/src/rslidar_sdk/config/config.yaml
，根据实际网络环境调整以下参数：
●
将
host_address
 设置为主机 IP（如
10.21.31.100
）；
●
为多雷达场景添加组播地址配置。
﻿
﻿
手动添加
组播地址
用于接收数据：
14
# 前雷达配置
- driver:
    lidar_type: RSAIRY
    msop_port: 6691
    host_address: 10.21.31.100     # 虚拟机接收IP
    group_address: 224.10.10.201  # 前雷达组播地址
# 后雷达配置
- driver:
    lidar_type: RSAIRY
    msop_port: 6692
    host_address: 10.21.31.100     # 虚拟机接收IP
    group_address: 224.10.10.202  # 后雷达组播地址

5.
服务挂起与话题接收
5.1
启动雷达组播转发服务
确保山猫已升级至V1.1.7及以上版本，雷达数据通过该服务（默认关闭）组播转发。启用步骤如下：
12
# 1. 设置服务开机自启（确保机器人重启后转发依然生效）
sudo systemctl enable multicast-relay.service
# 2. 立即启动服务（应用当前配置并开始数据转发）
sudo systemctl start multicast-relay.service
# 3. 检查服务运行状态（应显示绿色的 active (running)）
sudo systemctl status multicast-relay.service
# 4. 查看实时转发日志（确认是否有数据流出，按 Ctrl+C 退出查看）
sudo journalctl -u multicast-relay.service -f
服务运行时，状态显示为active（running）。

5.3
查看点云话题数据
在订阅话题前，请确保虚拟机与机器狗导航主机（
10.21.31.106
）网络连通：
3
# 检查是否能访问机器人转发网口
ping 10.21.31.106
确认网络畅通且驱动正常运行后，可通过以下命令查看点云数据流：
3
# 以前后（rear）雷达独立话题为例
ros2 topic echo /rslidar_points_rear
