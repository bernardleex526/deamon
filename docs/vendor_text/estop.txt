﻿
1. 概述
硬急停通过机器人
尾部
的红色物理急停旋钮操作，用于紧急情况下立即切断关节动力。硬急停只能在该物理按钮上手动触发和恢复，不提供软件控制接口。
触发硬急停后，所有关节电机进入断电保护状态，机器人立即停止运动。
﻿
﻿
2. 状态读取 — basic_server
硬急停触发状态通过 
Type=1002 Cmd=6
（基础状态上报，2Hz 主动推送）中的 
HES
 字段获取：
字段
值
含义
HES
0
未触发
HES
1
已触发
JSON 上报示例
11
{
  "PatrolDevice": {
    "Type": 1002,
    "Command": 6,
    "Time": "2026-05-20 10:00:00",
    "Items": {
      "HES": 1
    }
  }
}

3. 状态读取 — ROS2
话题名
/HES_STATUS
说明
硬急停状态
消息类型
drdds/msg/StdMsgInt32
频率
1Hz
依赖服务
rl_deploy
话题可见性
31+33网段的主机上可见
drdds/msg/StdMsgInt32 定义如下：
2
int32 data
值
含义
0
硬急停未触发
1
硬急停已触发
﻿
﻿
4. 注意事项
●
硬急停触发后，需
手动旋转释放
尾部急停按钮方可恢复。
●
恢复后机器人依然保持趴下状态。
●
硬急停优先级高于所有软件指令，包括软急停。
