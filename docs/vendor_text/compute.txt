2.2 二开程序绑核建议
注意
：RK3588 的小核（0-3）性能偏低，资源紧张，且
CPU0
被大量用于处理硬件中断和系统中断。如果开发者的二次开发程序运行在机器人内部任一主机上，
建议优先绑定到大核（CPU 4-7）上运行
，以获得更好的计算性能，也避免与核心进程竞争小核资源。
9
# 使用 taskset 将程序绑定到大核（core 4-7）
taskset -c 4-7 ./your_program
# 示例：绑定 Python 脚本到大核
taskset -c 4-7 python3 your_node.py
# 示例：绑定 ROS2 节点到大核
taskset -c 4-7 ros2 run your_package your_node
﻿
2.3 查看核心使用情况
10
# 查看各核心实时使用率
htop          # 按 F2 设置 → Display options → 显示核心编号
mpstat -P ALL 1  # 每秒刷新各核心使用率
# 查看进程当前绑定的核心
taskset -cp <PID>
# 查看 CPU 核心在线状态
cat /sys/devices/system/cpu/online
